# Phase 10 Hydrological Evidence Validation

## Objective
The objective of Phase 10 is to determine whether changes in vegetation condition are accompanied by changes in surface-water spectral condition by implementing an independent **Hydrological / Surface-Water Evidence Track** using available Green and NIR bands. This track serves as supporting evidence and does not independently prove physical wetland depletion.

## Input Data
The inputs used for this phase are aligned T1 and T2 rasters generated by the Phase 2 alignment pipeline:
* **green.tif**
* **nir.tif**

For the real data test, the dataset pair `2023-08-14` (T1) and `2023-08-28` (T2) was utilized.

## NDWI Implementation
NDWI was calculated using the formula:
$$\text{NDWI} = \frac{\text{Green} - \text{NIR}}{\text{Green} + \text{NIR} + \epsilon}$$
with:
* Configurable $\epsilon = 1 \times 10^{-6}$ (to prevent division-by-zero or instability).
* Float32-compatible vectorized NumPy implementation.
* Robust NoData propagation where invalid input pixels are preserved as `-9999.0` (never silently converted to `0.0`).
* Finite output checks and clipping to the range `[-1.0, 1.0]`.

## T1 Results
The T1 NDWI map (`ndwi_t1.tif`) was successfully generated for `2023-08-14`. The values range between `-1.0` and `1.0` for valid pixels, with a provisional water threshold of `0.0` applied to determine T1 water extent.
* Total water area detected in T1 (valid overlap area): **216.9635 ha**
* Total water area detected in T1 (wetland-restricted area): **173.9667 ha**

## T2 Results
The T2 NDWI map (`ndwi_t2.tif`) was successfully generated for `2023-08-28` using the same grid and parameters.
* Total water area detected in T2 (valid overlap area): **195.8808 ha**
* Total water area detected in T2 (wetland-restricted area): **150.0740 ha**

## Delta NDWI
The temporal NDWI difference map (`delta_ndwi.tif`) was calculated as:
$$\Delta\text{NDWI} = \text{NDWI}_{T2} - \text{NDWI}_{T1}$$
* Positive values represent increase in surface-water spectral signals.
* Negative values represent decrease in surface-water spectral signals.
* Near-zero values indicate stable spectral signals.

## Water Masks
Water masks were generated for T1 (`water_mask_t1.tif`) and T2 (`water_mask_t2.tif`):
* `0` = non-water (NDWI < threshold)
* `1` = water (NDWI >= threshold)
* `255` = NoData (propagated invalid pixels)

Both dates use the same threshold of `0.0` (labeled as **PROVISIONAL ENGINEERING THRESHOLD**).

## Water Change
The water change categorical map (`water_change.tif`) was generated with transition states:
* `0` = stable non-water
* `1` = stable water
* `2` = water gain
* `3` = water loss
* `255` = NoData / invalid

This was mapped from the internal compact transition ID formulation (`water_t1 * 2 + water_t2`) to the public IDs.

## NoData Validation
It has been verified that NoData values propagate correctly:
* Input NoData pixels (or pixels outside the common overlap mask) are preserved as `-9999.0` in the float32 outputs (`ndwi_t1`, `ndwi_t2`, `delta_ndwi`) and as `255` in the categorical outputs (`water_mask_t1`, `water_mask_t2`, `water_change`).
* NoData was never confused with water or non-water during classification.

## Spatial Validation
The output rasters preserve exact spatial metadata of the common aligned reference grid:
* **CRS:** EPSG:32632
* **Transform:** Same origin and pixel sizes.
* **Dimensions:** 2240 rows x 2248 columns.
* No shift, rotation, scale, or coordinate system mismatch occurred.

## Scientific Limitations
* A decrease in NDWI indicates surface-water spectral change. It can result from multiple factors such as reduction in surface water, vegetation stress/phenology changes, background soil effects, sensor geometry differences, or threshold placement.
* Therefore, NDWI decrease alone does not prove physical wetland depletion.
